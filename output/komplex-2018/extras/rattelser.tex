\subsection*{Mellansteg som rättats efter kontrollräkning}
Alla slutsvar i anteckningarna har räknats om oberoende (126 kontroller, se nedan) och stämmer.
Följande mellansteg var dock felaktiga trots rätt slutsvar:

\begin{description}[leftmargin=3.2em,style=nextline]
  \erratum{7}{$\dots = \dfrac{df}{dx}(x_0, y_0) + i\dfrac{dv}{dx}(x_0, y_0)$}{$\dfrac{du}{dx}(x_0, y_0) + i\dfrac{dv}{dx}(x_0, y_0)$}
  \erratum{8}{''får $\dfrac{du}{dy} = 2x$''}{$\dfrac{du}{dx} = 2x$ (för $u = x^2 - y^2$)}

  \erratum{39}{$u_{xx}$, $u_{yy}$ och $\Delta u$ för $u = \frac{x}{x^2+y^2}$}{$u_{xx} = \dfrac{2x^3 - 6xy^2}{(x^2+y^2)^3}$, $u_{yy} = \dfrac{6xy^2 - 2x^3}{(x^2+y^2)^3}$, summan $0$}
