\fbox{3.14} \quad Hitta en Mavb $M(z) = \dfrac{az + b}{cz + d}$ s.a.\ $M(0) = i$, $M(1) = 1$, $M(\infty) = -i$

\textbf{Lösning:} $0 \mapsto i$ \quad $\dfrac{b}{d} = i$ \quad sätt $b = i$, $d = 1$

\qquad $\infty \mapsto -i \Rightarrow \dfrac{a}{c} = -i$ \quad $c = ia$ \quad $\Rightarrow M(z) = \dfrac{az + i}{iaz + 1}$

$M(1) = \dfrac{a + i}{ia + 1} = 1 \Rightarrow a = 1 \quad \Longrightarrow M(z) = \dfrac{z + i}{iz + 1}$
